카네기멜런대(CMU) 컴퓨터과학대학(Kenneth C. Griffin School of Computer Science)이 무료 온라인 학습 플랫폼 [CS Learn](https://www.cs.cmu.edu/learn/)을 열었다. CMU는 2026년 11월 16일 [보도자료](https://www.cmu.edu/news/stories/archives/2026/november/cmu-opens-access-to-top-computer-science-classes-through-free-cs-learn-platform)로 이를 알렸다.

- 지금은 실제 강의실 수업을 녹화한 영상을 [유튜브 CMULearn 채널](https://www.youtube.com/@CMULearn)에서 무료로 볼 수 있다.
- 다음 단계는 실제 CMU 수업으로 만든 자기 주도 코스웨어다. 바로 채점되는 연습과 배지를 붙이고, 이후 AI 튜터링도 넣을 계획이다. 코스웨어도 무료라고 밝혔다.
- 가입이나 수강료 없이 영상을 바로 보면 된다. 코스웨어 소식은 [알림 신청 폼](https://forms.cs.cmu.edu/262996219823066)으로 받을 수 있다.

## 지금 볼 수 있는 수업

11월 23일 기준 [CS Learn 페이지](https://www.cs.cmu.edu/learn/)에 올라온 유튜브 강의는 8개다.

| 과목 번호 | 과목 | 교수 |
| --- | --- | --- |
| 10-605 | Machine Learning with Large Datasets | William Cohen |
| 15-110 | Principles of Computing | Franceska Xhakaj |
| 17-214 | Principles of Software Construction | Hammad Ahmad |
| 15-442 | Machine Learning Systems | Tianqi Chen, Zhihao Jia |
| 17-635 | Software Architectures | Swarnalatha Ashok, Scott Pavetti |
| 17-643 | Quality Management | Jeffrey Gennari, Christopher Timperley |
| 11-768 | AI Agents | Daniel Fried, Graham Neubig |
| 17-645 | Machine Learning in Production | Christian Kästner, Bogdan Vasilescu |

2027년 1월에는 Probability and Computing(15-259), Multimodal Machine Learning(11-777), Product Management Essentials(17-619), AI and Machine Learning I(07-280), Requirements for Embedded Systems(17-627)가 추가로 공개될 예정이다.

## 어떻게 만들었나

보도자료에 따르면 강의실 녹화를 온라인용 영상으로 바꾸는 과정에 CMU 학생 단체 [ScottyLabs](https://scottylabs.org/)가 만든 AI 보조 시스템을 쓴다. 덕분에 원래 수업 뒤 몇 주 안에 영상이 올라올 수 있다고 한다. 수업 중 학생 질문과 교수 답변도 남긴다. 학생 얼굴은 흐리게 처리하고, 질문 음성은 지우는 대신 화면 자막으로 보여 준다.

## 볼 만한 이유

AI Agents(Graham Neubig 외), Machine Learning Systems(Tianqi Chen 외), Machine Learning in Production(Christian Kästner 외)처럼 지금 현업 개발자가 궁금해할 주제를 해당 분야 연구자가 직접 가르치는 수업을 한 학기 분량 그대로 볼 수 있다. 소프트웨어 설계와 품질 관리 수업도 있어서, AI 도구로 코드를 많이 만들게 된 요즘 기본기를 다시 보기에도 좋다.
